# The Terminal
The Terminal är en webbapp (webbplats) som ser ut och fungerar som en Terminal med anpassade kommandon m.m. Butik/e-handel kan enkelt inkluderas. Annorlunda på så vis att besökaren "tvingas" agera genom att interagera med appen genom att faktisk skriva.
